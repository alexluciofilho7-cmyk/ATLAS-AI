## [C] GUIA VISUAL (BRANDING)

Passe estas instruções ao designer/desenvolvedor para garantir que o site não pareça genérico.

### 1. Identidade "Cyber-Athlete"
*   **Conceito:** Uma mistura de Apple (clean/premium) com Cyberpunk (futurista/dados).
*   **Paleta de Cores:**
    *   **Fundo:** Preto Profundo (`#0A0A0A`) e Navy Escuro (`#050A14`). Nada de cinza claro ou branco no fundo.
    *   **Acento (O "Neon"):** Azul Elétrico (`#00F0FF`) ou Ciano. Use para Botões, Ícones e detalhes de borda.
    *   **Texto:** Branco Puro para títulos, Cinza Médio (`#A0A0A0`) para parágrafos.

### 2. Tratamento de Imagens
*   **Regra de Ouro:** Todas as imagens de fundo devem ter um "overlay" (camada preta com transparência) para que o texto branco seja legível.
*   **Mockups:** O celular deve parecer tecnológico. Use sombras coloridas (glow azul) atrás do aparelho para dar profundidade.
*   **Pessoas:** Prefira fotos com iluminação dramática, suor, foco. Evite fotos de banco de imagem com gente sorrindo falso apontando para salada.

### 3. Elementos de UI
*   **Botões:** Arredondados, cor Neon com texto Preto (alto contraste), efeito de brilho (shadow) ao passar o mouse.
*   **Cards de Planos:** Fundo preto, borda fina cinza. O card "Intermediário" deve ter borda Neon e brilho sutil para chamar atenção.
